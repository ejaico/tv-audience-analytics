Public TV Viewing Data Source
Source

Nielsen Data Center — Top 10

https://www.nielsen.com/data-center/top-ten/

Data Used

This project uses a small sample of publicly available Nielsen Top 10 television viewing data.

The dataset contains:

Streaming television rankings
Linear television rankings
Reporting period
Program name
Rank
Platform
Network or streaming provider
Viewers P2+ where publicly available
Minutes viewed where publicly available
Household rating where publicly available
Number of episodes where publicly available
Measurement Differences

Streaming and linear television metrics are not treated as directly interchangeable.

The public Nielsen streaming table reports total minutes viewed by persons 2+.

The public Nielsen linear TV table reports total viewers P2+ and household rating.

Where a metric is not provided by the source, the corresponding field is left blank rather than estimated or fabricated.

Purpose

The public dataset is used to add real-world television viewing context to the project and demonstrate how public content and audience data can be incorporated into an analytical workflow.

Limitations

This is a small public-data sample and is not a complete Nielsen dataset.

The project does not use Nielsen proprietary client data.

The project does not represent production experience with Nielsen measurement products or proprietary audience-level data.

The project later combines these public data with clearly labeled synthetic household-level viewing data for educational and portfolio purposes.
